# CL0P and Third-Party Software Exploitation

## Status

**Research not started**

## Project Relevance

This profile will use CL0P-related MOVEit activity as a case study in third-party software compromise, mass data theft and extortion. The focus is not only the actor name, but how one vulnerable supplier or managed service can expose many downstream financial organisations.

Associated labels such as CL0P, Lace Tempest, TA505 and FIN11 will be kept source-specific because public reporting does not always describe identical activity clusters.

## Intelligence Questions

1. How did exploitation of third-party file-transfer software create downstream exposure?
2. Which victim and supplier dependencies matter to financial services?
3. How did the actor move from exploitation to data discovery, collection and extortion?
4. Which application, identity, API, vendor and data-transfer logs would reveal the activity?
5. Which third-party risk, patching, segmentation and data-minimisation controls reduce impact?
6. Which parts of the case remain actor-specific and which represent a repeatable supply-chain attack model?
