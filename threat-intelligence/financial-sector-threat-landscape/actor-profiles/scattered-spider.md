# Scattered Spider / UNC3944

## Status

**Research not started**

## Project Relevance

This profile will examine a financially motivated activity cluster associated with help-desk social engineering, MFA-reset abuse, cloud identity compromise, SaaS access, virtualisation, data theft and extortion.

The profile will use `Scattered Spider / UNC3944` as a working label while recording how MITRE, Mandiant, Microsoft and other sources define associated names.

## Intelligence Questions

1. How does the actor obtain or reset credentials and MFA methods?
2. Which cloud identity, SaaS and virtualisation platforms have been abused?
3. What evidence supports financial-services targeting during the selected period?
4. Which actions are difficult to distinguish from legitimate administration?
5. Which identity-provider, help-desk, SaaS, cloud and hypervisor logs are required?
6. Which controls would stop or contain the attack path?
